# 《逆命江湖》P3-C | 图块细节与方向动画

## 已做
1. 三张地图的独立基础 Tile 增加更丰富的材质微纹理：细草、花点、石板拼缝、瓦片暗线、水面波纹、岩石裂纹、木质纹理。通过 SVG atlas 的**每个32px图块局部纹理**实现，没有用整场景大背景冒充地图。
2. 五名游戏内角色沿用正式角色 PNG 母版：沈砚、韩掌柜、苏晚晴、顾老、山贼；各自形成 **四方向 × 四帧** 的可替换方向图集（192×256）。
3. 浏览器脚底定位、朝向检测、连续像素平滑移动、动画帧切换和摄像机插值。
4. Pygame 版同步解析方向动画 SVG 并逐帧播放；遇到环境无法解码时明确日志提示并使用原单帧 PNG 降级。
5. 增强 npm/Python 回归验收，确保 P3-B 三地图剧情和存档不被改坏。

## 必须诚实区分的美术状态
五套 SVG 方向图集是从现有**已审核 Q 版 PNG**派生的预制作动画。
- 下方向直接使用母版前视
- 左/右方向是镜像、轻微变形和头发轮廓的临时派生
- 上方向是用背部头发/外衣遮罩制作的临时背面
- 动画步态是躯干上下与下摆左右的二维错位，不等于完全绘制的四向骨骼动画。

**因此 P3-C 的渲染能力已接入，但不能把方向派生稿谎报为已通过的独立正式角色四向立绘。** 当前还不是第三张图的最终精细程度。
必须让 Qwen 以`逆命江湖_群侠绘卷.png`作为官方母版，逐人物绘制 front/back/left/right 4视角、每视角 idle+walk3 共 16 PNG。独立成图后自动输出同样192×256的spritesheet PNG，并替换这个 SVG 的路径。不能只是把正面镜像。
详见 `assets/characters/scene_sprites/sprite_manifest.json`。后续先完成沈砚16帧并严格验收脸/衣服/身高/步态一致，再批量角色，最后增加战斗挥剑、受击动画。
