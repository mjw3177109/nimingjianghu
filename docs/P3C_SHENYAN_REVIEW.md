# P3-C / 沈砚方向动画 — 可视化验收与替换条件

新绘制的像素游戏展示图中包含沈砚四行六列动作示例，此补丁提取每个方向四帧，以 PNG Alpha 贴图方式组织成真正的角色资源。**这和之前从正面 PNG 做镜像的四方向过渡图不同。**

候选产物：
- 高质量原始192x256 Sprite Sheet和16个独立48x64帧：位于下载的 P3-C Shenyan 候选 ZIP；未自动批准
- GitHub试玩预览专用优化版：`assets/characters/scene_sprites/candidates/player_4dir_preview.png`，96x128（每帧24x32，在引擎中放大2倍到48x64）
- 网页：在 Vercel 预览URL后加 `?shenyan=16` 激活；
- Windows Pygame：环境变量 `NIMING_PREVIEW_SHENYAN16=1` 后运行 main.py
- 默认状态仍是已测试稳定的旧图集。不改角色属性，不改坐标、碰撞、地图数据和任何存档。

## 机检情况
- 16张RGBA帧，角落透明；
- 足底统一锚点，统一48×64；
- 每帧和同方向静止帧图像差异明显，未出现完全重复帧；
- 同一张展示图内含正、背、左、右分别绘制的形象；
- 但生成展示图不是独立角度角色设计母版，因此需要人工确认脸、长发、腰带、黑白红服装是否与原始CHAR001人设一致。

## 注意
1. 预览版 PNG 为节约网络带宽做了像素降采样（96x128），不替代192x256高质量母版。
2. 独立动画帧应审核通过后才使用工具`python tools/pack_sprite_sheets.py --character CHAR001 --input <目录> --approve`切换稳定资源。
3. 不得拿整张游戏截图作为可玩地图，也不得镜像正面图冒充背面。
4. 即使机器检测合格，也不能把人工美术QA标记成通过。

## 首章回归
新旧角色只改变绘制，不应改变青石镇、山贼、山洞、命痕等剧情触发。
