# P3-D：首页高清化与黄色路线框越界修复

## 用户反馈与根因
- 首页菜单、人物说明、玩法预览全是 300～500px 宽的 WebP 面板，包含 AI 烘焙中文错字；在现代桌面 1000px+ 容器里直接 `background-size:100% 100%` 拉伸，造成文字和人物模糊。
- 游戏 Canvas 的像素缓冲区仅 640×360，再用 CSS 放大到桌面宽；浏览器二次缩放导致像素画面模糊。
- 寻路目标黄框按世界地图坐标绘制，即使目标在镜头外也会尝试画到 viewport 之外。

## 变更
- 改成可编辑 DOM 菜单、角色卡、场景标题。中文文案不再来源于截图。
- SVG 矢量月夜国风背景，原生 1920×1080，任意缩放无失真，也不含文字。
- 三张首页实时 Tile 预览，以地图 JSON + Atlas 独立渲染，完全删除旧预览截图入口。
- Canvas 使用1280×720 bitmap + CSS比例仍为16:9，游戏逻辑坐标依旧640×360，绘制使用 `ctx.setTransform(2,0,0,2)`。
- 寻路黄框只有当世界目标格的屏幕坐标完整落在逻辑屏幕 `[0,640)×[0,360)` 内才绘制；镜头外不会出现飘出去的框。
- 独立 Node.js 自动测试校验页面中文、边界、资源和三张预览。

## 尚未解决的美术范围
首页角色头像仍是既有小尺寸 WebP，真实精细头像、独立立绘、全员四方向 Sprite 仍需要正式高清生成后批量替换。这轮不声称所有绘制图都已达4K，也不对现有低清图做AI虚假补画。

## 验收
`npm test` 和 `npm run build`，然后人工检查 1920×1080 / 1366×768 / 375px 手机排版与实际寻路。
