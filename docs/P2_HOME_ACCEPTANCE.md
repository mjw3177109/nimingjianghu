# P2 首页验收矩阵

| ID | 范围 | 验收动作 | 阻断条件 |
|---|---|---|---|
| H-001 | 初次加载 | 新隐私窗口打开首页，确认首次只出现HOME | 未点开始就进入地图/对白 |
| H-002 | 三列布局 | 与视觉锚点 C 对比左菜单/中主角/右四卡 | 只使用旧网页上层装饰 |
| H-003 | 正式美术 | 图A同一人脸、同服装、无扁平SVG冒充 | 角色与母版不同或占位图当正式 |
| H-004 | 中文 | 所有文字来自DOM，检查角色名称 | AI错字、乱码、角色串名 |
| H-005 | 无存档 | “继续游戏” disabled，提供提示 | 无存档仍可启动异常状态 |
| H-006 | 开始新游戏 | 点击开始进入第一章并播放首段对白 | 页面卡死/重复触发 |
| H-007 | 存档兼容 | 注入旧版 v02 保存数据后点击继续 | 损坏既有用户进度 |
| H-008 | 返回首页 | 游戏内返回首页再继续 | 跳帧/多次RAF/对白重复 |
| H-009 | 角色卡 | 4张可 hover+click 查看说明 | 死按钮 |
| H-010 | 设置/图鉴/回顾/关于 | 均可打开及返回 | 空白页/无法返回 |
| H-011 | 三宫格 | 实机截图与当前对应场景一致 | 虚构的宣传图冒充游戏 |
| H-012 | 响应式 | 390、1024、1440、1920 宽度检查 | 主按钮不可见、人物脸被裁切 |
| H-013 | 性能 | 预加载核心资源并处理加载失败 | 图片未到先乱跑剧情 |
| H-014 | 发布 | CI校验、Git commit、Vercel READY、HTTP200 | 仅 README 宣称成功 |
