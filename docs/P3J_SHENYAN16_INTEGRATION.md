# P3-J｜全新沈砚16帧已实际接入游戏

## 实际资源
- 原始生成素材：`武侠忍者少年行走精灵图表.png`，1086×1448，RGBA透明；SHA256：459a92dcb368c6b91ad5b6ddc00fe06325b27f357af4f8ff53ebf78195e7b4c4。
- 将四行（正面、左侧、右侧、背面）与四列（待机、步态1、步态2、步态3）分别裁出，统一中心与脚底锚点。
- 游戏中上传的优化透明图集：`assets/characters/scene_sprites/player_4dir.png`，384×512，每帧96×128，PNG SHA256：be0f8405b3e9e551a6521f563af75d204b945ffbbbe48b2bcc77828e8d78660c。
- 无损整理RGBA图集、16张独立帧、动态GIF和详细质量JSON在本轮提供的下载ZIP中保留。

## 游戏接入
- 浏览器读取`sprite_registry.js`中的新图集，将人物按朝向与动作从整张PNG中每次裁切一帧，整张角色一次性绘制；不再拆成上半身与下半身。
- Windows/Pygame读取`sprite_manifest.json`，主角`CHAR001`会在开发试玩分支使用新16帧PNG；其他角色仍使用原有完整人物单图。
- 保留地图格子、寻路、场景模块、碰撞、任务、剧情、首页主视觉、头像和旧存档。
- 运行时资源状态为`gameplay_trial_pending_user_art_review`，并非正式商业美术审核已通过。审核页左侧显示已经集成到可玩游戏的新图，右侧仍提供旧低清候选对照。

## 仍要人工确认的视觉事项
- 新人物动作是否接地自然，双脚是否滑动。
- 正背侧面人物服装、发型、腰带和剑是否跟首页角色一致。
- 新素材是否满足最终高清目标（当前每帧96×128，是游戏运行分辨率，不是1536px独立原画）。
- 有无残留红色毛边、轮廓抖动与帧间身高变化。

## 自动回归
`npm run build`会对资源签名、384×512尺寸、49,015字节和SHA256进行强校验，同时检查两端Sprite路径和第一章剧情模拟。部署READY后仍需浏览器实机人工评审。
