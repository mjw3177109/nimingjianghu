# 《逆命江湖》P3-E | 原生高清 Tile 图集与分辨率契约

本阶段新增 **独立绘制的 64×64 SVG 图块图集**（不是32px栅格放大），以既有地图 JSON 中的图块类型为输入，程序化产生细节、质感和颜色变化，并供网页与Pygame显示。
原版32px 图块仍保留，作为兼容回退。关键原则：**Tile源图分辨率升级不修改32px逻辑格子、地图网格、NPC位置或物理碰撞。**

- 青石镇 36 种，6×6，高分图集 384×384
- 山路 30 种，6×5，高分图集 384×320
- 废弃山洞 30 种，6×5，高分图集 384×320
- 共96种源图块，每个64×64。
- `node tools/p3e-hd-atlas.cjs` 生成三张`_hd64.svg`；
- `npm run build` 每次生成、回归测试后才发布；
- 网页根据`naturalWidth / atlas_columns`自动裁图，首页三张 Tile 预览同步。
- Pygame运行前可生成同一套HD图块，自动从64px源图做缩放到32px逻辑Tile；缺图时使用旧32px稳定资源。
- 图块的语义和层结构保留，可日后用Qwen2.1分别生成真正美术母版并原位替换`_hd64`资源。

## 质量说明
这里的高清是**新绘制的64px细节纹理**，不是旧32px放大；仍然是程序生成原型美术，不等于用户指定的三张官方Q版截图达到影视级一致。高精度角色母图、独立四方向手绘与逐块Qwen微调后才能达到最终视觉标准。
避免跨分支素材来源漂移；强制图片无文字，所有物品文字只能由DOM/Canvas实时渲染。

## 验收
`npm test`运行图块数量、源分辨率、语义、客户端引用、旧业务测试及Python测试。
