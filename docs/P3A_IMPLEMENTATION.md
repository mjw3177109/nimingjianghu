# P3-A 青石镇模块化地图｜运行版

已从原画整图方案切换为真实图块拼接，不使用 S001_town.webp 作为游戏内背景。地图库数据来源 data/maps/town/town_tilemap.json；静态浏览器用生成的 town-tile-data.js 同步加载。

- 格子：32px，地图：40×24，视口：640×360，摄像机跟随。
- 图块：36 种程序绘制像素 Tile（atlas 是 6×6 原始模块而不是切割旧场景图）。
- 分层：ground、水面、building、deco_low、actors、front；碰撞逻辑独立。
- 核心布局：西客栈、东药铺、南北河道、中部石桥、镇东出口、韩掌柜/苏晚晴/顾老。
- 首章任务、存档、战斗逻辑不变。P3-A 第一批素材为程序绘制的独立原型图块；长期正式美术可遵循同一格子 ID 使用 Qwen 官方母版逐项替换。
- 计划127项的资源清单仍存在于单独P3A生产包；此时 runtime atlas 实现其中 36 种基础材质/装饰，不代表127项都已出图。
- 完整青石镇视觉/人物四方向 Sprite、美术精修与同步 Windows 渲染须独立验收，不可误报完成。
