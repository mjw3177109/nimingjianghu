# 逆命江湖 Niming Jianghu — Demo v0.2 可玩 Demo

原创像素武侠 RPG，沈砚误入江湖，主角只能独自战斗，幕后操盘者为廖。

## 在线浏览器试玩

打开仓库根目录 `index.html`，也可以使用任意静态服务器发布本仓库根目录。网页版本无需安装依赖。

## Windows Pygame 启动

```powershell
python -m pip install -r requirements.txt
python main.py
```

* 鼠标左键点击地面自动寻路；点击 NPC、山贼、光点、出口互动。
* 对话时按 `Enter`、空格或鼠标继续。
* 战斗时按 `1~4` 选基础剑法、破风一剑、疗伤药、防御。
* 逻辑分辨率 640×360，显示 1280×720；素材最邻近放大。

## 剧情闭环

穿越 → 青石镇 → 韩掌柜接任务 → 山路击败山贼 → 山洞秘籍 → 命痕石台 → 返回青石镇 → 廖的伏笔。

## 地图与美术

`assets/maps/S001_town.svg`、`S004_road.svg`、`S005_cave.svg` 为本项目原创像素地图图像（文本 SVG 内嵌无损像素 PNG），可直接由浏览器加载。相同场景的 PNG 被打包在下载 ZIP 中，或执行 `python tools/generate_assets.py` 重新生成。`assets/sprites/*.png` 是本期可用的正式比例像素精灵初版，后续可由 Qwen 官方角色母版替换。

地图目前是 **原创程序化像素绘制的美术初版**，不是 Qwen 生图，也不是第三方付费素材。属于可实际加载的地图，不仅是提示词；后续正式精修可以保持坐标与碰撞数据不变替换图片。

世界地图、任务和对话定义在 `data/world.json`，浏览器引用打包好的 `world-data.js`。修改数据后运行 `python tools/export_world_js.py` 同步网页数据。

## 边界

这是 3 地图、1 战斗、1 武学获得和逆命伏笔的可玩垂直切片，并非 30 章完整游戏。没有把原《金庸群侠传2》的人物、场景或对话搬入。


## Q版美术升级 v0.2

浏览器版采用 5 张新的 Q版原创角色 SVG（主角、韩掌柜、苏晚晴、顾老、山贼）和 3 张重绘的游戏地图 SVG（青石镇、山路、山洞），统一暖色江湖界面。新增 localStorage 自动存档、对话角色头像、战斗角色立绘。代码及美术均保留数据驱动路径方便后续替换用户正式 Qwen 母版。

Pygame 版保留兼容资源；浏览器版是本次 Q 版美术的主要验收目标。
