# 逆命江湖 · 精致国风Q版 Demo V1.0

**[在线试玩（2026-10-20 更新）](https://nimingjianghu-mrvnwcxqh-bobos-projects-e9f8bfba.vercel.app/)** ｜ [开发分支](https://github.com/mjw3177109/nimingjianghu/tree/feat/playable-demo-v0.1)

当前版本是**可通关第一章的 Demo**，不是全部30章正式游戏。

这是 **第一章正式试玩版**，并非完整30章游戏。美术严格遵循已确定的三张视觉锚点：
- 角色锚点：六人水墨国风 Q 版绘卷，统一身份与服饰
- 实机锚点：青石镇、地图游戏 HUD 与对白风格
- 首页锚点：月夜大主视觉、六个菜单、角色卡、三张玩法预览

本项目使用用户提供的原始设计图裁切制作：首页菜单 / 人物图鉴 / 游戏地图 / 对话头像 / 行走角色 / 战斗气氛。**部分地图背景仍保留了参考画面里原先绘制的静态人物；它们是场景装饰，不是可交互 NPC。** 实际可移动角色、NPC、任务与战斗由代码驱动，后续做长期正式版时需重新生产无人物干净地图、多方向 Sprite 和可寻路遮挡数据。

## 网页玩法
`index.html` 可直接作为静态资源发布，进入主菜单后选择“开始游戏”。支持继续游戏、角色图鉴、设置说明、剧情回顾、人物卡查看。

## Windows Pygame
```powershell
pip install -r requirements.txt
python main.py
```
本地与网页版共用正式手绘地图（WebP）和角色 PNG。两套客户端交互外壳有差异。

## Demo 第一章完整闭环
穿越 → 青石镇客栈接任务 → 山路山贼战斗 → 洞穴拾取《破风一剑》 → 命痕石台触发逆命值+25 → 返回青石镇 → 廖的伏笔。

node --check game.js

## 本次资源定位
直接使用三张审批母图做出的**完整第一章可玩 Demo 视觉版本**，不代表30章商业游戏整体完成。正式人物三维动作、背景静态人物清理和复杂战斗动画属于后续完整游戏工作。


## 发布验收说明

- 运行 `npm test` 检查首页、任务闭环和正式图片的完整性。
- Vercel `npm run build` 在静态文件发布前自动执行同样的测试，缺关键人物、地图或资源引用将失败。
- 角色图鉴、青石镇、山路战斗、废弃山洞和第一章尾声均在此版本交付。
- **已知限制**：参考图裁切场景含静态背景人物；浏览器真实交互人物是单独渲染的精灵。Windows 版和浏览器版 UI 不完全一致。
- 自动测试覆盖剧情关键事件，但不等于全部真实浏览器/Windows设备人工验收。
